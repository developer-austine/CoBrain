# 01 · Architecture

## The four processes

| Process | Tech | Responsibility |
|---------|------|----------------|
| **Web app** | Next.js 16 (App Router, Turbopack), React 19 | UI, API routes, server actions, auth, orchestration |
| **Ingest worker** | Python | Pops the Redis queue, runs the processing pipeline, writes vectors |
| **Search API** | Python + FastAPI | Embeds a query, searches Qdrant, returns ranked chunks |
| **Celery worker / beat** | Python | Scheduled + background connector syncs |

Backed by four stores:

| Store | Holds | Why |
|-------|-------|-----|
| **Postgres** | Workflows, connections, ingested records, BrainBlocks, chat | The **source of truth**. Citations resolve here. |
| **Qdrant** | Chunk vectors + payload (`source`, `namespace`, `parent_doc_id`) | Semantic search |
| **Redis** | The `company_brain:ingest` queue | Decouples ingestion from the request cycle |
| **MinIO** | Uploaded file bytes | Data sovereignty — files stay in your stack |

> **Auth is a separate database.** Better Auth uses its own Postgres
> (`AUTH_DATABASE_URL`, typically Neon); business data uses `DATABASE_URL`.
> They are deliberately not the same database.

### A write (`WRITE`)

The key subtlety: **`@brain` is the destination, never the thing you read.**
"Edit the `@brain` page with tasks from `@notion`" must read *Notion*.

## Design rules (do not break these)

1. **Postgres is truth; Qdrant is an index.** A vector is worthless without its
   `parent_doc_id`. Never render an answer from Qdrant text alone — always
   resolve the id so the user gets a real link.

2. **Mentions are structured tokens, never parsed text.** The prompt box submits
   `{ text, references: [{type,id,label}] }`. Do not regex `@notion` out of a
   string — a user may legitimately type an email address.

3. **Scope the search or email will win.** Email out-volumes everything. If a
   query names a source, the vector search is **filtered** to it. See
   [03-intelligence-layer.txt](./03-intelligence-layer.txt).

4. **Regroup chunks into documents before synthesis.** A flat top-k of chunks
   lets one chatty document crowd out every other document, producing a single
   narrow answer. `groupChunksByDocument()` is what makes "list every task
   across all my Notion pages" work.

5. **Every AI write is provenanced and reversible.** `sourceRefs` on a
   `BrainBlock` points at the exact documents it was derived from. Low-confidence
   writes land in a review queue, not on the page.

6. **`namespace` and `source` must stay indexed in Qdrant.** Without keyword
   payload indexes, every filtered search full-scans the collection and times
   out. `ensure_payload_indexes()` runs on search-api startup. See
   [06-operations.txt](./06-operations.txt#known-failure-modes).

## Why the pieces are where they are

- **`lib/` holds pure domain logic** with no I/O where possible
  (`sourceIntent`, `documents`, `knowledgeScope`, `sourceScope`,
  `sources/constants`). That is why they are unit-testable without a database
  and why the test suite runs in seconds.
- **`actions/` are server actions** (mutations invoked from client components).
- **`app/api/` are route handlers** — used where we need streaming (SSE),
  webhooks, OAuth callbacks, or file bytes.
- **Python owns the pipeline** because the ML libraries (sentence-transformers,
  presidio, spaCy) live there. It does **not** own the schema — Prisma does.
  Python reads/writes tables that Prisma defines.
