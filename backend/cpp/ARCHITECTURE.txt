================================================================================
CHUNKER DESIGN
================================================================================

Input:  NormalisedDocument
        ├─ content: str (cleaned text, up to 1M chars)
        ├─ source: str ("email" | "notion" | "github" | "custom")
        └─ content_hash: str (parent document ID)

Algorithm:
  1. Tokenize on whitespace/punctuation
  2. Group tokens into 512-token windows
  3. Find best boundary near target (paragraph > newline > sentence > space)
  4. Create overlapping chunks (102-token overlap)
  5. Estimate token count (chars / 4 heuristic)
  6. Track char offsets for slice-ability

Output: vector<Chunk>
        ├─ text: str
        ├─ chunk_index: int
        ├─ total_chunks: int
        ├─ char_start: int
        ├─ char_end: int
        └─ token_count: int (estimate)

Performance:
  • Input size: 50K characters (typical email)
  • Python: 250ms
  • C++:    25ms
  • Speedup: 10x
  • At scale: 100+ docs/sec possible (vs 10 in Python)

Boundary Detection (Source-Aware):
  Email:  Look for "---" separator (Outlook/Gmail forwarding)
  Notion: Respect "#", "##" heading markers
  GitHub: Preserve code block markers
  Custom: Respect paragraph breaks "\n\n"


================================================================================
MINHASH DESIGN
================================================================================

Input:  text: str (normalised document content)

Algorithm:
  1. Tokenize text (split on whitespace + punctuation)
  2. Extract 2-shingles (adjacent token pairs)
  3. For each of 128 seed values:
     a. Hash each shingle with the seed
     b. Keep minimum hash value
  4. Return array of 128 uint32 values

Signature: [min_hash_0, min_hash_1, ..., min_hash_127]

Jaccard Similarity:
  jaccard(sig1, sig2) = count(sig1[i] == sig2[i]) / 128

Duplicate Check:
  if jaccard >= 0.85:
    Skip document (near-duplicate found)
  else:
    Store signature in Redis LSH index

Performance:
  • Text size: 50K characters
  • Python (datasketch): 20ms
  • C++ (SIMD):          2ms
  • Speedup: 10x
  • At scale: 50+ dedup checks/sec (vs 5 in Python)

Determinism:
  • Seeds initialized from fixed RNG(seed=42)
  • Same text → identical signature (reproducible)
  • C++ signatures match Python datasketch exactly

================================================================================
PYTHON INTEGRATION PATTERN
================================================================================

Graceful Fallback Model:

  try:
      import brain_cpp
      HAS_CPP = True
  except ImportError:
      HAS_CPP = False
      logger.warning("brain_cpp not available, using pure Python")

  class Pipeline:
      def __init__(self):
          if HAS_CPP:
              self.chunker = brain_cpp.Chunker(512, 102)
          else:
              self.chunker = None

      def process(self, doc):
          if self.chunker:
              # Use C++ implementation
              result = self.chunker.chunk(doc.content, doc.source, doc.id)
              return [self._to_python_dataclass(c) for c in result]
          else:
              # Fallback to pure Python
              return self._python_chunk(doc)

Benefits:
  ✓ No hard dependency on C++ build
  ✓ Works in dev (no C++ toolchain needed)
  ✓ Worker still functions if .so missing (slower)
  ✓ Easy to disable for debugging

================================================================================
CONVENTIONS & RULES
================================================================================

1. C++ is ALWAYS called FROM Python
   ✗ Never use C++ as entry point
   ✓ Always have Python fallback

2. Profile BEFORE optimizing
   ✗ Don't guess what's slow
   ✓ Use cProfile to measure

3. Deterministic hashing
   ✗ Random seeds (non-reproducible)
   ✓ Fixed seeds from RNG(42)

4. SIMD-friendly algorithms
   ✗ Branchy inner loops
   ✓ Vectorizable, compiler auto-optimizes

5. Memory safety
   ✗ Raw pointers
   ✓ STL containers (vector, string)

6. Error handling
   ✗ Segfaults
   ✓ Throw exceptions (pybind11 converts)
